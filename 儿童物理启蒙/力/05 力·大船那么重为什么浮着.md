# 力·大船那么重为什么浮着？

## 先问孩子

> 一块铁扔水里会沉。可是几万吨的钢铁大船为什么浮着？
> 大船是不是"比较轻"？

## 可以做的小实验

**实验 1：橡皮泥的魔法（最推荐）**
1. 拿一团橡皮泥，直接丢进水里 → **沉底**
2. 把同一团橡皮泥捏成小船的形状 → **浮起来**
3. 再往小船里放硬币，直到它沉 → 数一共放了几枚
4. 结论：**同样的重量，形状不同，浮沉就不同**

**实验 2：为什么？因为排开的水不一样**
- 沉下去的那团：只挤开很少的水
- 浮着的小船：中间有空气，挤开了更多的水
- 用大杯子接住溢出的水，称一称溢出的水量 → 会发现跟船重差不多

**实验 3：鸡蛋浮沉（最直观）**
1. 一杯清水，放鸡蛋 → **沉**
2. 一勺一勺加盐，边加边搅 → 鸡蛋慢慢**浮起来**
3. 结论：**盐水更"重"（密度大），托得更有力**

**实验 4：潜水艇原理（玩水时可以做）**
- 塑料瓶里放一个小吸管/小药瓶，做成"浮沉子"
- 挤压瓶身 → 小瓶下沉；松手 → 上浮
- 因为进水/排水改变了它的重量

## 一句话原理

> [!important] 记住这句
> **水会给泡在里面的东西一个向上的托力，叫浮力。**
> **排开的水有多重，浮力就有多大。**（阿基米德原理）

铁的密度比水大，所以铁块会沉。但把铁做成空心的船，船 + 空气的整体"平均密度"就比水小了 → 所以浮着。

## 生活中的例子

- 轮船、竹筏、木船
- 死海：盐特别多，人躺着就浮起来
- 游泳时吸气会浮，呼气会沉
- 气球在空气里"浮"（空气也有浮力）
- 煮饺子：先沉后浮，因为受热膨胀、密度变小

## 和孩子聊什么

> 如果海水里的盐再多一点，船是不是能装更多货？
> 那你说，为什么在死海里人根本沉不下去？
