# 折纸·小盒子 📦

> [!success] 成品
> 一个**方方正正的小纸盒**，**真的能装东西**（小石子、橡皮、糖）。
> 🔑 **折两个不同大小的，还能"盖起来"**，变成一个**有盖的盒子**。

## 📄 用什么纸

| | |
|:---|:---|
| **首选** | **14cm 正方形**（折出来约 5cm 见方） |
| 也可以用 | A4 裁出的 21cm 正方形（大盒子） |
| 💡 | **厚一点的纸更结实**（能多装点东西） |
| 🎯 **想做"有盖的盒子"** | **盒身用 14cm，盒盖用 14.5～15cm**（🔑 **盖必须比身大一点点**，才盖得上） |

## 🪜 一步一步折

> [!important] 记得：**每步都用指甲刮平**（盒子要**四个角一样**，不然不方）

**第 1 步·折出"米"字折痕**
正方形：
- **对角折**两次（两条对角线）→ 展开
- **对折**两次（横竖）→ 展开
→ 纸上有 **"米"字折痕**（4 道）

**第 2 步·四个角折向中心**
把**四个角**分别折到**正中心** → 压平
→ 变成一个小正方形

**第 3 步·把边折向中线（三折法）**
把**上边**往上折，让边对齐**中线** → 压平
→ 但**折完先展开**（只留折痕）
**左右两边**同样：各自折到中线 → 展开（留痕）
→ 现在四周有 **4 道"往里折"的折痕**

**第 4 步·剪开两个对角（关键）**
把纸**展开到第 2 步的样子**（四个角都聚在中心）→
**沿"上下"两条对角的折痕，各剪开一刀**（剪到中间小正方形的边为止）→
→ 🔑 **注意：只剪两条，另外两条不剪！**（这是盒子能立起来的关键）

**第 5 步·立起两侧**
- 把**左右两片**（有剪口的）**竖起来**，当盒子的**两个侧壁**
- 把**上下两片**（没剪的）**往上折，盖在侧壁外面** → 
- 上下两片的**小三角**，分别**包住侧壁的口、塞进去**

**第 6 步·压平、整形**
把四边都捏一下，让盒子**四个角挺起来**
🎉 **小盒子完成！**

**第 7 步·（可选）做盖子**
用**稍大一点的纸**（14.5～15cm）**重复以上全部步骤** →
→ 就得到一个**能盖上的盖子**

## 🎁 里面装什么

| 装什么 | 用途 |
|:---|:---|
| **小石子 / 贝壳** | 他在外面捡的"宝贝" |
| **橡皮 / 小玩具** | 桌面收纳 |
| **糖 / 小零食** | 送人（装进去更正式） |
| **折好的小鱼/星星** | 收作品 |
| **纸条（写心愿）** | "许愿盒" |

> [!tip] 🎯 最好的用法：**做个"宝贝盒"**
> 让辰星**自己去外面捡 5 样东西**（石头、树叶、瓶盖）→ 装进盒子。
> **再让他给盒子起个名字**（"辰星的宝箱"）→ 他会很珍惜。

## 🧠 顺手讲的知识

- **为什么纸盒能装东西**？（🔑 **折痕让纸"变硬"了** —— 平的纸一压就垮，折过的边能"立"）
- **为什么盒盖要比盒身大一点**？（**不然盖不进去** —— 这就是"**尺寸配合**"）
- 📌 **纸箱、快递盒都是这个原理**（折痕 = 骨架）
- ✅ 顺便认字：**盒、方、装、开**（可加进他的识字清单）
- 🔑 **和物理呼应**：[[01 力·为什么推得动桌子]] 讲的是"力"，这里讲的是**形状决定强度**（同样的纸，折了就能承重）

## 🎮 加一点玩法

1. **"套娃盒"**：折 3 个**越来越小**的盒子，套在一起
2. **"礼物盒"**：装一颗糖送奶奶
3. **"收纳盒"**：在桌上放 3 个，分别装橡皮、铅笔头、贴纸
4. **"藏宝图"游戏**：把一个小纸条藏在盒子里，让对方找

---

> [!warning] 安全提醒
> - 🔴 **第 4 步剪两刀 → 由家长剪**（剪到中间要停，别剪过头）
> - ⚠️ **别用太硬的卡纸**（折不动，边缘会割手）
> - ⚠️ **别把盒子套在手上/头上**（会卡住）
> - ⚠️ 装过零食的盒子**别再装不能吃的东西**（纸有颜料）
> - ✅ 折完写名字（做多了会混）
