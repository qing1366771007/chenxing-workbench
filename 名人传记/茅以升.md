# 茅以升（桥梁专家）

> **姓名**：茅以升（1896年—1989年）
> **出生地**：江苏镇江
> **身份**：桥梁专家、中国科学院院士
> **成就**：主持建造钱塘江大桥，中国人自己设计的第一座现代化大桥
> **名言**：人生一征途耳，其长百年，我已走过十之八九。回首前尘，历历在目。

---

## 一、人物简介

茅以升是中国著名的桥梁专家。他小时候亲眼看到秦淮河上的桥塌了，很多人掉进水里，就下定决心：长大了一定要造最结实的桥。后来他真的成为了桥梁专家，主持建造了中国人自己设计的第一座现代化大桥——钱塘江大桥。

## 二、立志造桥

茅以升小时候住在南京，秦淮河是他常去玩的地方。有一年端午节，河上赛龙舟，特别热闹，很多人挤在桥上看。结果桥塌了，好多人掉进了水里。

小以升难过极了，他暗暗发誓：我长大了一定要造最结实的桥！从那以后，他特别留意各种各样的桥，看到桥就要研究半天。

## 三、建造钱塘江大桥

1934年，茅以升开始主持建造钱塘江大桥。很多外国人都说：中国人根本不可能在钱塘江上造桥，因为那里的水流太急，地质太复杂。

但茅以升不信这个邪。他带领团队，克服了无数困难，用了两年半时间，终于把大桥建好了！1937年9月，钱塘江大桥通车，全中国人民都沸腾了——这是中国人自己设计、自己建造的第一座现代化大桥！

## 四、炸桥与复桥

大桥刚建好没多久，抗日战争就爆发了。为了不让日本人利用大桥，茅以升不得不亲手指挥炸掉了自己花了几年心血建成的大桥。他说："抗战必胜，此桥必复！"

抗战胜利后，茅以升果然又把大桥修好了。这座桥至今还在使用，已经八十多年了，依然非常坚固。

## 五、主要成就

| 成就 | 说明 |
|------|------|
| 钱塘江大桥 | 中国人自己设计建造的第一座现代化大桥 |
| 武汉长江大桥 | 参与设计了万里长江第一桥 |
| 桥梁教育 | 培养了大批桥梁工程人才 |
| 科普教育 | 写了很多科普文章，让更多人了解科学 |

## 六、给孩子讲茅以升的小故事

1. **"争气桥"**：钱塘江大桥被人们称为"争气桥"，因为它是中国人靠自己的力量造出来的，打破了外国人说中国人不行的预言。每次看到这座桥，人们就会想起茅以升爷爷和他说的那句话：中国人是有能力的！

2. **从小认真观察**：茅以升小时候每次看到桥，都要仔细观察很久：桥是怎么造的？为什么能承受那么大的重量？他还会把桥画下来，记在本子上。正是从小养成的认真观察的习惯，让他后来成为了了不起的桥梁专家。
