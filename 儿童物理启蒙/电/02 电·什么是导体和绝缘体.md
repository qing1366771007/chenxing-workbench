# 电·什么是导体和绝缘体？

## 先问孩子

> 为什么电线里面是铜，外面要包一层塑料？如果整根都是铜，会发生什么？

## 可以做的小实验

**实验 1：会导电吗？测一测**
- 材料：电池 + 小灯泡 + 导线（中间留两个"测试夹"）
- 把不同东西接进这个缺口，看灯亮不亮：
  - 钥匙 → 亮（金属）
  - 铅笔芯 → 有点亮（石墨能导电）
  - 橡皮、塑料尺、木筷子、纸 → 不亮
  - 一杯水 → 不亮；**加一勺盐搅匀 → 亮了！**
  - 自己的舌头、手指（湿的）→ 微亮

**实验 2：盐水实验（最让孩子惊讶）**
- 一杯清水不导电，加盐后导电
- 结论：**水本身不导电，水里的"盐粒子"导电。** 汗手比干手更危险就是这个道理。

## 一句话原理

> [!important] 记住这句
> **容易让电通过的东西叫导体（金属、水、人体）；不容易让电通过的叫绝缘体（塑料、橡胶、干燥的木头、陶瓷）。**

口诀：**"金石墨水人"能导电，"塑胶干木陶"不导电。**

## 生活中的例子

| 地方 | 里面 | 外面 |
|---|---|---|
| 电线 | 铜（导体） | 塑料皮（绝缘体） |
| 插头 | 铜片 | 塑料壳 |
| 电工手套 | — | 橡胶（绝缘） |
| 高压线塔 | 铝线 | 空气 + 陶瓷瓶 |

## 和孩子聊什么

> 为什么小鸟站在电线上不会被电到？
> 因为它的两只脚站在同一根线上，**没有形成"另一条路"让电流过去**。如果它一条腿在这根线、一条腿在那根线，就危险了。
