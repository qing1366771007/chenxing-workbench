# 磁·磁铁的秘密（N 极和 S 极）

## 先问孩子

> 两块磁铁放在一起，有时候"啪"地吸上去，有时候怎么按都按不到一起。为什么它有时候亲、有时候打架？

## 可以做的小实验

**实验 1：同性相斥、异性相吸（必做）**
1. 拿两块磁铁（标了 N/S 的那种）
2. N 对 S → 吸住了
3. N 对 N → 明显推开了！用力按都按不拢
4. S 对 S → 也推开
5. 结论：**同极相斥，异极相吸**

**实验 2：找出磁铁的"两极"**
- 把磁铁放在铁屑（或用回形针代替）里滚
- 会发现两头粘的最多 → 那里是磁极
- 中间几乎不粘 → 说明**中间磁力最弱**

**实验 3：切开的磁铁还是两块磁铁**
- （家长切）把一条条形磁铁切成两段
- 每段自己都有 N 极和 S 极！
- 再切一次还是一样 → 永远切不出"只有 N 极"的磁铁

**实验 4：磁铁悬浮（视觉冲击最强）**
- 找两个环形磁铁，一个套在铅笔上，另一个从上面丢下去
- 因为它俩同极相对，第二个会**悬浮**在空中

**实验 5：磁化与消磁**
- 用磁铁摩擦一根铁钉 → 铁钉也能吸回形针（被磁化了）
- 把铁钉在桌上敲几下、或用火烧一下 → 磁力消失（消磁）

## 一句话原理

> [!important] 记住这句
> **磁铁有两极：N 极和 S 极。同极相斥，异极相吸。**
> 这两个极永远成对出现，**切也切不开**。

**电和磁的关系（预告）：**
- 有电在流动 → 周围就有磁场（奥斯特发现）
- 有磁铁在动 → 就能生出电（法拉第发现，见 [[05 电·磁铁怎么就能发电]]）
- **电和磁本来就是一家人**

## 生活中的例子

- 磁悬浮列车：靠"同极相斥"把车身托起来，几乎没有摩擦，所以能跑超快
- 扬声器 / 耳机：磁铁 + 线圈振动发出声音
- 磁力门吸、冰箱门封条
- 电磁铁：通电有磁、断电没磁（起重机吸废铁就靠这个）

## 和孩子聊什么

> 磁悬浮列车为什么能跑那么快？因为它**不接触轨道**，没有摩擦。
> 那你想想——如果没有摩擦，我们走路会怎么样？（走不了，每走一步都会滑倒。）
